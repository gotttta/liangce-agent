# 线宽／间距量测

确认量测对象、ROI 和单位；核对原图叠加、Mask 与轮廓，不为预期数量或尺寸裁剪结果，默认不做形态学或面积过滤。当前标准运行时的长度／面积仅报告 pixel／pixel²，不得冒充物理单位。指标须有实际执行的计算和产物依据；缺少算子可构造并执行 generated_operators，未计算则报告未完成。记录方法、参数、单位及有效／无效样本，执行成功不等于验收通过。

## 量测口径

1. 确认线条方向、边缘定义、取样位置，以及间距指边到边还是中心到中心。

2. 沿线条局部法向建立截线，计算边缘交点距离；输出每个取样位置及宽度、间距的最小值、均值、最大值和分布。

3. 倾斜线条不能使用轴对齐边界框宽度替代线宽；断线、交叉、端点或边缘不清的样本需标记无效。

## 验收

验收项：sampling_direction、edge_definition、valid_cross_sections。

按图像选择目标提取算法；需要详细参数时通过 query_operators 批量查询所需算子。允许组合多个量测 Skill，不绑定固定 Pipeline。
